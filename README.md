merhaba bu proje TBP4001 mobil programlama için yaptığım günlük harcama takip uygulaması. ionic ve angular kullandım aslında internetten örnek baktım bi kısmını kendim uydurdum.

ne işe yarıyo:

harcama adı tutar kategori giriyosun bos bırakırsan eklemiyo
liste ngfor ile geliyo
toplam yukarda hesaplanıyo
sağa kaydırınca sil var silmeden once uyarı cıkıyo
veriler localstoragede duruyo sayfayı yenileyince silinmiyo
ekleme silmede toast var
kategoriye gore renk var tarih de var
calıstırmak için:

npm install
ionic serve
bazen npx ionic serve yazıyorum o da oluyo. tarayıcıda localhost 8100 acılıyo genelde

kodlar src/app/home altında home.page ts html scss var. en üste hocanın istediği yorum satırını yazdım

github: https://github.com/chillaizen/harcama-ionic
